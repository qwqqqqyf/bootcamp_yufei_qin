# Stakeholder Brief — S&P 500 Sector Performance Analysis

**Audience:** Portfolio manager  
**Decision supported:** Historical comparison during sector-allocation review

## Context

Different S&P 500 sectors can have materially different returns and volatility. A consistent, repeatable comparison helps a portfolio manager evaluate historical risk-return behavior without treating past performance as a forecast.

## What the project provides

- sector-level daily returns and cumulative performance;
- volatility and rolling-volatility comparisons;
- a table and visualizations for historical risk-return review.

## Assumptions and limits

Sector SPDR ETFs are used as investable proxies for sectors. ETF fees, tracking error, changing composition, missing observations, and market events can affect the comparison. Results are descriptive decision support, not investment advice.
